    A harness for your harnesses

    Harness Reins¶

    把训练、测试、长时间实验和子 Agent 交给独立的系统进程托管。Agent 不必守着等待；任务一结束，结果就回到发起它的那个会话。Codex、Claude Code、Pi 都能用。

    开始使用 看实测数据

    8× 更省钱 3 天任务前 60 小时：¥35 对比 ¥287

    72 h 进程被杀也跑完 不用 Reins 的那一组当场失败

    2 秒 结果回到原会话 任务结束到会话恢复的中位延迟

    一个任务，五步走完¶

    在 Agent 会话里提交一条训练命令：

    reins run --cwd "$PWD" --task "训练模型" -- python train.py --config configs/exp.yaml

    Reins 立刻返回任务 ID 和日志路径，Agent 结束回合。任务结束后，同一个会话收到回调，Agent 检查输出并执行回调里的 ACK 命令。 第一次使用可以先按快速开始跑一个十秒钟的示例。

    接入你的环境¶

    Reins 支持 Linux、macOS 和 Windows。按安装指南配置运行环境，再选择你的 Agent： Codex CLI、Claude Code、Pi 或 Codex Desktop。 Harness 支持情况列出了各接入方式的版本和回调路径，典型使用场景给出了完整的工作流程示例。
