    A harness for your harnesses

    Harness Reins¶

    Hand training runs, test suites, long experiments and child agents to an independent system process. The agent doesn't have to wait up: when the work finishes, the result comes back to the session that asked for it. Works with Codex, Claude Code and Pi.

    Get started See the benchmark

    8× cheaper first 60 h of a 3-day task: ¥35 vs ¥287

    72 h finished despite the kill the run without Reins failed on the spot

    2 s back in the same session median time from task end to resumed turn

    One task, five steps¶

    From the agent's session, submit a training command:

    reins run --cwd "$PWD" --task "Train the model" -- python train.py --config configs/exp.yaml

    Reins returns a task ID and a log path at once, and the agent ends its turn. When the task finishes, the same session receives a callback; the agent checks the output and runs the ACK command it contains. Start with the ten-second example in Your first task.

    Set up your environment¶

    Reins runs on Linux, macOS and Windows. Follow Installation, then choose your agent: Codex CLI, Claude Code, Pi or Codex Desktop. The support matrix lists versions and callback routes, and Use cases walks through complete workflows.
